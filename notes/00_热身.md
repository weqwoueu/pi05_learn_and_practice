## 要完成什么

- `split_heads`：输入 [B,N,D]，输出 [B,heads,N,head_dim]；D 不能整除 heads 时抛 ValueError。元素顺序必须正确。
- `merge_heads`：做逆变换，支持 transpose 后不连续的张量。
- `masked_mean`：x 为 [B,N,D]，valid 为 [B,N]。只对有效 token 沿 N 求平均，输出 [B,D]。整条样本无有效 token 时输出 0，其梯度也应有限。

手算例子：三个 token 是 [1,2]、[999,999]、[5,6]，mask 是 [真,假,真]，结果应是 [3,4]。

## 分层提示

<details><summary>提示一：先标维度</summary>

拆头先把最后维拆成 heads × head_dim，再交换 token 和 heads 维。合头先交换回来。

mask 应扩为 [B,N,1]。分母应统计有效 token 数，而不是固定 N，也不是 N×D。
</details>

<details><summary>提示二：常见错误</summary>

transpose 改变 stride，直接 view 可能失败；考虑 reshape，或 contiguous 后再 view。

分母至少取 1，保证全无效样本不会除零。别通过 detach 或重新构造 torch.tensor 截断输入梯度。
</details>
