# 05 把小型动作专家接通

需要查函数或类时，打开 [API 速查](Torch与Python_API速查.md)，按顶部题号表阅读。可以看着 API 写第一遍。

实现：[ex05_expert.py](../exercises/ex05_expert.py)。检查：`uv run python run.py 05`。建议 60—90 分钟，先完成 02、03、04。

## 练什么

输入已经编码好的 prefix（代替图像、任务和状态 token），带噪动作与去噪时间，输出动作速度。测试检查信息流与反向路径。

| 变量 | 形状 |
|---|---|
| prefix | [B,P,D] |
| prefix_valid | [B,P] |
| noisy_actions | [B,H,A] |
| τ | [B]，或 RTC 扩展的 [B,H] |
| 输出速度 | [B,H,A] |

## 实现要求

A. time_embedding：D 为不小于 4 的偶数。D/2 个 period 在 min_period=0.004 与 max_period=4 之间按几何比例分布。角度为 2π·τ/period，先拼所有 sin，再拼所有 cos，输出 [...,D]。

B. prefix_suffix_mask：输出 [B,1,P+H,P+H]，True=允许。有效 prefix 内部互看；prefix 不看动作；动作能看有效 prefix 和全部动作。padding query 的整行应为 False。

以 P=2、H=3、prefix 全有效为例，行为 query、列为 key：

```text
       p0 p1 a0 a1 a2
p0      1  1  0  0  0
p1      1  1  0  0  0
a0      1  1  1  1  1
a1      1  1  1  1  1
a2      1  1  1  1  1
```

C. forward，严格采用本题定义的教学结构：

1. action_in 将 noisy_actions 投影至 D。
2. time_embedding → time_mlp，得到时间条件。
3. adaptive_norm(action_tokens,cond) 得到 modulated、gate。
4. 入口时间残差：action_tokens = action_tokens + gate × modulated。
5. 沿 token 维拼 prefix 与 action_tokens，用上述 mask 逐层通过 blocks。
6. 取最后 H 个 token，output_norm → action_out，得到速度。
7. return_prefix=True 时返回 (速度, 更新后的 prefix)，便于检测 prefix 是否偷看动作。

## 与真实 π0.5 的区别

本题只有统一宽度 D、共享参数的 Transformer，并且只在入口调制一次；省略视觉编码器、真实 tokenizer、RoPE、GQA、KV cache。它用来训练数据流和张量实现能力。

真实 [gemma_pytorch.py](../../openpi/src/openpi/models_pytorch/gemma_pytorch.py) 中，PaliGemma 与动作专家有各自的参数，hidden width 可以不同；分别做 QKV 投影后，在兼容的注意力空间按序列维拼接，再把结果分给各自的输出投影/MLP。π0.5 时间条件传给动作专家的各层 adaRMS。面试时要能明确说出这些差别。

## 分层提示

<details><summary>提示一：不要在宽度维拼 prefix 和动作</summary>

本题 prefix 和动作宽度都为 D，拼接后是 [B,P+H,D]。mask 中 prefix→action 的右上角应全为 False。

period 使用浮点数，并跟随 τ 的 device。τ 增加最后一个维度后再除以 period。
</details>

<details><summary>提示二：时间梯度与零初始化</summary>

adaptive_norm 的调制层零初始化，所以初始 gate 为 0，模型初始输出可能不随 τ 改变；不代表线路接错。测试会主动设置非零调制参数后检查时间依赖。

不要为了让初始输出依赖 τ 而擅自对 gate 加 sigmoid；它会改变题目定义。
</details>
