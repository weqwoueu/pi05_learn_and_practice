## 确认时的候选题目记录

0. 热身，约30分钟：reshape/transpose/广播、masked mean、检查形状；只补基础，不独立扩展成大量题。
1. 状态到 token，45-60分钟：quantile 归一化与逆变换、状态离散化、构造 Task/State 文本、padding/mask；解释 π0 的连续 state token 与 π0.5 的离散文本路径。保留 tokenizer 适配接口，真实分词与教学占位实现明确区分，不假设每个数字刚好一个 token。测试边界、shape、归一化近常量维度。
2. Attention，60-90分钟：单头到多头、Self/Cross Attention、padding 与 causal mask；数值对齐 PyTorch 参考实现，检查不同 query/key 长度。全被屏蔽的行明确约定行为，避免 NaN。
3. Transformer block，60-90分钟：RMSNorm、残差、gated MLP；增加时间条件的 scale/shift/gate，解释 adaRMS。分步骤搭建，不一次要求写完整大模型。
4. Flow Matching 与 CFG，60-90分钟：采样 tau 与噪声、构造 x_tau、监督 epsilon-action、loss reduction、Euler 从1到0采样、两分支 CFG。用解析简单向量场检查采样方向。
5. 简化动作专家综合题，90-120分钟：复用已有模块，接入给定的图文 prefix embedding、动作线性投影、时间条件、prefix/suffix block attention mask，输出 [B,H,A] 向量场，运行一次 loss/backward。明确这是教学简化版，视觉编码器提供现成输入，不声称复现完整 PaliGemma/Gemma 双专家。
6. 微调与梯度排错，45-60分钟：写 optimizer 训练步；冻结中间 backbone 后验证前置 adapter 仍有梯度；区分 requires_grad/no_grad/detach/eval；识别错误的 loss 归约或梯度清零位置。LoRA 作为选做扩展。
7. RTC，60-90分钟：0..6步前缀采样、逐token时间条件、后缀loss归一化、推理固定前缀；补一道旧chunk/newchunk时间索引题。推理时VJP用小函数演示，完整guidance系数不要求背写。
8. Value/Advantage，45-60分钟：two-hot交叉熵、分布期望、N-step advantage、终止bootstrap、只对自主帧算分位数；覆盖人工帧、重复阈值、短轨迹和恒定负value。

1-6为核心，7-8为与项目对应的专项。若时间不足，专项采用补全与调试，优先保证Attention、Flow Matching、数据路径能独立复写。

选做扩展：RoPE/GQA、prefix KV cache、LoRA Linear、GAE/PPO clipped loss，以及每天一道20分钟Python基础题。是否增加由用户确认；不默认增加完整PPO、SAC、DPO或训练大模型的任务。

每题提供：中文题面、输入输出shape、TODO骨架、可执行测试、分层提示。核心实现不用 nn.MultiheadAttention 或 nn.Transformer 代写；可在测试中作参考。答案按需提供。
